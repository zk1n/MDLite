# 編集・検索ガイド

Markdownソースが正本です。Live表示の書式、表の表示、検索ハイライトだけでは本文を変更しません。

## 表のLive編集

表はセル内だけを編集し、パイプと区切り行は通常の削除操作から保護します。セル中のパイプはMarkdownへエスケープして保存します。Tab／Shift+Tabは次／前セル、Enter／Shift+Enterは下／上セルへ移ります。最後のセルからのTabと、最終行からのEnterは行を追加します。矢印移動では行を追加しません。セル内のHome／Endはセルの先頭／末尾へ移動します。

表ごとに内容とフォントから列幅・行高を測ります。横幅が編集面を超える表は表内だけで横スクロールします。表示用の子RichEditも同じ文書ソースとUndo履歴を使い、別文書として保存しません。表上部の操作帯はホバーまたは操作中に表示され、セルにカーソルを置いただけでは表示しません。

表の操作帯からソース表示を切り替えられます。検索が非表示の構文へ移動するため一時的に開いたソース表示は、検索終了などで解除します。利用者が手動で開いたソース表示はそのまま保ちます。矩形のTSV貼り付けは対象範囲に収まる場合だけ適用します。

## 検索と置換

Ctrl+Fは現在の文書、Ctrl+Shift+FはWorkspace検索を左サイドバーに開きます。入力に応じて検索し、結果をファイル別に表示します。検索欄は複数行の貼り付けを保持します。大小文字、単語一致、正規表現、include／exclude、ignoreの設定を変更できます。開いている未保存文書はメモリ上の本文を検索し、古い検索結果は文書や検索条件の変更後に適用しません。

表示可能な一致を本文にハイライトし、現在の一致を区別します。非表示の表構文の一致ではソース表示へ移動します。Escapeや閉じる操作で検索を終了します。IME変換中はEscapeを検索終了として扱いません。

Workspace置換は変更前後をファイルごとに確認してから適用します。検索エラー、走査・結果の上限到達、プレビュー後の本文変更などがある場合は適用を止めます。画像等の既知のバイナリと再解析ポイントは除外として示し、本文の置換対象にしません。正規表現の実行時間、ファイル・結果数、プレビューサイズには上限があります。

閉じたファイルへの置換はWorkspace内の復旧ジャーナルへ記録します。「閉じたファイルの置換を戻す…」で対象ごとの変更前後を確認できます。現在のWorkspace、ジャーナル、各ファイルの内容を照合し、置換後に編集されたファイルや開いている対象文書がある場合は復旧を止めます。アプリ再起動後はジャーナルを選んで復旧できます。

## 確認の範囲

自動テスト、Win32の合成入力、OS経由のキー／マウス入力は、それぞれ実施した方法で記録します。物理キーの長押し、実際のIME／ATOK変換、複数DPI、読み上げや操作感の受入はHumanの実操作確認として扱います。
